====================================================================
MAKAO MVP: PRE-PITCH TEST PROTOCOL
====================================================================

PRE-FLIGHT INFRASTRUCTURE CHECKS
[ ] 1. Services Running:
    - Laravel backend running (php artisan serve)
    - React frontend running (npm run dev)
    - Python FastAPI service running (uvicorn main:app --port 8001)
    - CRITICAL: Laravel Queue Worker running (php artisan queue:work). *If this is off, Observers will fire but jobs will never reach Python.*
[ ] 2. Environment Variables:
    - Laravel: LARAVEL_API_URL points to Python service.
    - Python: GOOGLE_API_KEY is valid, active, and has sufficient quota.
    - React: VITE_API_BASE_URL points to Laravel.
[ ] 3. Database State:
    - Seeded with at least 5 active properties (varying prices/locations).
    - Seeded with at least 3 leads.

--------------------------------------------------------------------
TEST SUITE 1: THE REVERSE MATCHING LOOP (New Lead -> Scan Properties)
--------------------------------------------------------------------
[ ] 1. Trigger: Create a new Lead in the CRM with kanban_stage = 'new'.
    - Requirements: Specific location and budget constraints.
[ ] 2. Queue Verification: Check Laravel terminal to ensure 'DispatchLeadMatch' processed successfully.
[ ] 3. FastAPI Verification: Check Python terminal for "Received match request for Lead ID: X".
[ ] 4. UI Verification: 
    - Refresh/Load the 'AI Triage Inbox'.
    - Verify the new match appears at the top.
    - Verify the match score makes logical sense based on the constraints.
    - Read the Gemini reasoning. Ensure it is blunt, accurate, and mentions the specific constraints.

--------------------------------------------------------------------
TEST SUITE 2: THE FORWARD MATCHING LOOP (New Property -> Scan Leads)
--------------------------------------------------------------------
[ ] 1. Trigger: Add a new Property or update an existing one to status = 'active'.
[ ] 2. Queue Verification: Check Laravel terminal to ensure 'DispatchPropertyMatch' processed successfully.
[ ] 3. FastAPI Verification: Check Python terminal for "Received match request for Property ID: X".
[ ] 4. UI Verification:
    - Open 'AI Triage Inbox'.
    - Verify the new property was matched to existing relevant leads.

--------------------------------------------------------------------
TEST SUITE 3: TRIAGE INBOX UI & ACTIONS
--------------------------------------------------------------------
[ ] 1. Data Hydration: Does the inbox load without a spinner freezing indefinitely?
[ ] 2. Selection State: Clicking different matches updates the right pane correctly.
[ ] 3. Dismiss Action:
    - Click "Dismiss Match".
    - Verify the match disappears from the left list.
    - Verify the right pane auto-selects the next available match (or shows the "Queue Cleared" empty state).
    - Verify the database updated the notification to 'read'.
[ ] 4. WhatsApp Deep Link:
    - Click "WhatsApp Lead".
    - Verify a new tab opens to web.whatsapp.com/wa.me.
    - Verify the phone number is stripped of characters (e.g., +254 700-000-000 -> 254700000000).
    - Verify the pre-filled message includes the Lead Name and Property Title.

--------------------------------------------------------------------
TEST SUITE 4: THE DRAFT PROPOSAL MODAL (Synchronous AI)
--------------------------------------------------------------------
[ ] 1. Trigger: Click "Draft Proposal".
[ ] 2. Loading State: Verify the button disables and shows "Drafting..." with a spinner.
[ ] 3. API Proxy: Verify Laravel receives the request and forwards it to Python.
[ ] 4. Generation Output:
    - Verify the modal overlay appears.
    - Verify the text generated is in the strict, professional, blunt persona we defined.
    - Verify the price formatting is correct (e.g., Ksh 85,000,000).
[ ] 5. Fallback Test: 
    - Temporarily kill the Python server (Ctrl+C).
    - Click "Draft Proposal".
    - Verify the system gracefully falls back to the hardcoded text instead of crashing the UI.
[ ] 6. Copy Action: Click "Copy & Close", verify modal closes, and paste into a notepad to confirm clipboard action.

--------------------------------------------------------------------
TEST SUITE 5: THE PITCH DAY "DISASTER RECOVERY"
--------------------------------------------------------------------
[ ] 1. What happens if the internet drops?
    - Keep a video recording of the "Golden Path" on your desktop to play if Wi-Fi dies mid-pitch.
[ ] 2. What happens if Gemini APIs timeout?
    - Ensure your fallback text logic is ready.


Pro-Tip for the Pitch

Never do live data entry for everything during a pitch—it slows down the momentum. 
Have a tab open with a pre-filled "New Property" form and a pre-filled "New Lead" form. 
When it's time to show the AI, just hit "Save", switch tabs to the Inbox, and let the background 
queues do the magic while you talk.
